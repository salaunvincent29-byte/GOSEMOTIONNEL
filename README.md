# GPS émotionnel V8

Version intégrée comprenant quatre chemins complémentaires :

1. **Questionnaire GPS** — observations corporelles et contextuelles ;
2. **Mon humeur en images** — sélection progressive de trois photographies parmi un corpus de 40 visuels ;
3. **Boussole émotionnelle** — identification ou correction manuelle ;
4. **Communiquer maintenant** — messages visuels, texte libre et synthèse vocale.

## Nouveau dans la V8

- onglet `Photos` dans la navigation principale ;
- 40 photographies embarquées et utilisables hors ligne ;
- 10 séries de 4 images, avec possibilité de passer ;
- présélection puis choix final de trois images ;
- calcul pondéré de l’état dominant et des hypothèses secondaires ;
- estimation qualitative de la cohérence ;
- enregistrement du résultat et des trois images dans l’historique commun ;
- ouverture directe de la boussole pour corriger l’hypothèse ;
- fonctionnement PWA hors ligne.

## Données et confidentialité

Les résultats et l’historique restent dans le stockage local du navigateur. Aucun compte ni transfert distant n’est nécessaire.

## Limites scientifiques

Le corpus et ses pondérations sont conçus pour un MVP. Ils ne constituent pas un test psychométrique validé. Une même photographie peut produire des associations différentes selon les personnes, les cultures et le contexte. Les pondérations doivent être recalibrées après des tests utilisateurs image par image.
