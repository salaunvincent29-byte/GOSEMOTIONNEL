# GPS émotionnel V7

Version unifiée comprenant :
1. Questionnaire GPS émotionnel ;
2. Boussole émotionnelle interactive avec aiguille manuelle ;
3. Module « Communiquer maintenant » ;
4. Historique local commun.

La cartographie corporelle a été supprimée. La boussole devient le seul module cartographique.

## Données
Stockage exclusivement local. Aucun compte, serveur ou transfert distant.

## Limites
Prototype d’accompagnement, non diagnostique et non validé comme dispositif médical.
